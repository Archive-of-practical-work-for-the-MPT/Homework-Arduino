# Практическая работа 8 - Управление сервоприводом и шаговым мотором

## Цель

Собрать схему из потенциометра, сервопривода и шагового мотора, подключить их к Arduino Uno.

1. Установить фреймворк PlatformIO в VSCode, создать новый проект, установить библиотеки Stepper.h и Servo.h
2. Подключить потенциометр к аналоговому пину А0, написать код для считывания данных с него.
3. Используя считанные с потенциометра данные, управлять углом поворота сервопривода. 
4. В зависимости от угла поворота сервопривода, регулировать скорость вращения мотора (чем больше значение угла поворота сервопривода, тем выше скорость вращения ротора мотора). 
5. Показать работу на железе на паре.
