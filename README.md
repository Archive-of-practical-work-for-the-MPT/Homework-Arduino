# Практическая работа 13 - Взаимодействие Arduino и Unity

## Цель

Собрать схему из микроконтроллера и джойстика.

1. Реализовать считывание данных с джойстика.
2. В прикрепленном проекте реализовать управление машиной с помощью
джойстика.
3. Показать работу на железе на паре.

Используйте протокол UART (Serial Port) для обмена данными.
