# Практическая работа 4 - Работа с Arduino с помощью C#

## Цель

Собрать схему из 2-х кнопок, 2-х светодиодов и пьезоэлемента.
Написать программу на WPF, в которой будет 2 объекта Button, один Label и один ComboBox. 
В ComboBox добавить элементы: "0.1 sec", "0.5 sec", "1 sec". 
1. Если кнопка S1 была нажата, в label в WPF-приложении выводится сообщение "Нажата первая кнопка". 
2. Если кнопка S2 была нажата, в label в WPF-приложении выводится сообщение "Нажата вторая кнопка". 
3. Если в WPF-приложении была нажата кнопка button1, то светодиоды начинают моргать с заданной в ComboBox частотой. 
4. Если в WPF-приложении была нажата кнопка button2, то пьезоэлемент начинает проигрывать мелодию (любую на Ваш выбор, но не менее 7 нот). 
5. Сдать работу на железе на паре.
