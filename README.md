# Практическая работа 10 - Работа с WiFi-модулем WeMos D1 R2. Разработка Telegram-бота

## Цель

Собрать схему из микроконтроллера, светодиода, резистора и сервопривода. 

1. Создать Telegram-бота через BotFather (название - Ваше ФИО) на основе скетча из лекции со следующим функционалом:
2. При отправке команды "ledOn", включить светодиод.
3. При отправке команды "ledOff", выключить светодиод.
4. При отправке команды "ledChangePower", изменить яркость светодиода на значение 128.
5. При отправке команды "Open", установить угол сервопривода на 180 градусов.
6. При отправке команды "Close", установить угол сервопривода на 0 градусов.
7. Показать работу на железе на паре.
