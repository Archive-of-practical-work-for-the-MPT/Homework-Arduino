# Практическая работа 12 - Работа с RFID-модулем

## Цель

Собрать схему из микроконтроллера, RFID-модуля и кнопки.
1. Реализовать процедуру проверки (авторизации) UID метки.
2. Создать в программе класс "Person" со свойствами Surname (String либо char*) и Balance(int),
пользуясь всеми правилами инкапсуляции и код-стайла.
3. Создать и записать в EEPROM-память экземпляр Person с вашими данными и начальным балансом 0.
4. При считывании RFID-метки увеличивать баланс объекта на 100 и обновлять данные в EEPROM.
5. При нажатии на кнопку выводить фамилию и баланс в Serial монитор.
6. Показать работу на железе на паре.
