# Практическая работа 1 - Реализация светофора на Arduino

## Описание

Этот проект демонстрирует реализацию базовой логики работы светофора с использованием Arduino, макетной платы, светодиодов и резисторов. Программа реализует следующую последовательность смены цветов:

*   Красный
*   Желтый
*   Зеленый
*   Зеленый моргающий
*   Желтый

## Цель

Собрать схему из микроконтроллера (Arduino Uno), макетной платы, 3 светодиодов и 3 резисторов. Реализовать последовательность смены цветов светофора (красный - желтый - зеленый - зеленый моргающий - желтый).

## Вывод
В результате выполнения проекта был создан функционирующий прототип светофора на базе Arduino. Данный проект является хорошей отправной точкой для изучения более сложных систем управления и автоматизации.
