# Практическая работа 11 - Создание гирлянды с настройкой через Bluetooth-модуль HC-06

## Описание
Как сделать чтобы работало?

- Соберите схему как на рисунках ниже, незабудьте подключить BT в Wokwi его нет.
- Скачайте на телефон любой BT Terminal я использовал [Bluetooth Terminal Manager](https://play.google.com/store/apps/details?id=com.ezee.btm)
- Загрузите скетч
- Через приложение подключитесь к BT он будет называться HC-06.
- Возможно потребует пароль, попробуйте 1234 или 1111
- Используйте команды такие как `MODE_1` в терминале для работы скетча

## Цель

Собрать схему из микроконтроллера, bluetooth-модуля HC-06, 6 светодиодов, 6 резисторов и кнопки.

1. При подключении к микроконтроллеру по Bluetooth в мобильное приложение (или терминал) выводится сообщение –
“Hi, I am <Фамилия И.О.>”
2. Командой "MODE_1" устанавливаем режим работы, при котором светодиоды просто горят.
3. Командой "MODE_2" устанавливаем режим работы, при котором светодиоды моргают по принципу четный-нечетный.
4. Командой "MODE_3" устанавливаем режим работы, при котором все светодиоды плавно загораются и плавно гаснут.
5. Командой "MODE_CHAOS" устанавливаем режим работы, при котором все светодиоды хаотично горят с рандомной
яркостью.
6. При нажатии на кнопку все светодиоды гаснут, в приложение (терминал) отправляется сообщение о прекращении
работы.
7. Показать работу на железе на паре.
