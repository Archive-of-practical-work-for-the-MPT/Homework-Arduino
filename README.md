# Практическая работа 6 - Работа со сдвиговым регистром и семисегментным индикатором

## Цель

Собрать схему из сдвигового регистра, семисегментного индикатора и пьезоэлемента.

1. Реализовать обратный отсчет от введенной пользователем цифры (1-9) до нуля, с выводом на семисегментный индикатор. 
2. Когда отсчет заканчивается, пьезоэлемент начинает воспроизводить мелодию. 
3. Сдать работу на железе на паре.
