# Практическая работа 2 - Интерфейс UART

## Цель

Собрать схему, состоящую из 3-х кнопок и 3-х параллельно подключенных между собой светодиодов. 
1. При нажатии на 1-ую кнопку первый раз, светодиоды загораются. При нажатии второй раз - гаснут
2. При нажатии на 2-ую кнопку яркость светодиодов должна меняться в диапазоне от 0 до 255. Если значение превышает 255, светодиод гаснет. Должно быть реализовано не менее 5 шагов изменения яркости (5 кликов на кнопку).
3. При нажатии на 3-ю кнопку, в монитор порта должно выводиться ваше ФИО. 
4. При вводе символа "M", светодиоды начинают моргать и не заканчивают до тех пор, пока не будет выполнено другое действие (нажата кнопка или введен другой символ).
5. При вводе символа "S", светодиоды гаснут.

## Вывод
В результате выполнения проекта был создан функционирующий прототип светофора на базе Arduino. Проект позволил закрепить знания о работе с цифровыми выходами Arduino, подключении светодиодов и написании простых программ для управления электронными компонентами. Данный проект является хорошей отправной точкой для изучения более сложных систем управления и автоматизации.
