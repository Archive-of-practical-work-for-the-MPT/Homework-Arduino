# Практическая работа 3 - Работа с EEPROM
## Цель

Собрать схему из 3-х кнопок и 4-х светодиодов.
Написать программу, которая сохраняет в энергонезависимую память количество нажатий кнопок S1 и S2. 
1. Если кнопка S1 была нажата четное количество раз, горит светодиод D1, светодиод D2 гаснет; нечетное количество раз - горит светодиод D2, светодиод D1 гаснет. 
2. Если кнопка S2 была нажата: четное количество раз, горит светодиод D3, светодиод D4 гаснет; нечетное количество раз - горит светодиод D4, светодиод D3 гаснет. 
3. Параллельно информация о количестве нажатий дублируется в COM-порт.
4. Кнопка S3 обнуляет значение переменных в EEPROM.
